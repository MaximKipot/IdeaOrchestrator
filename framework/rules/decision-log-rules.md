# Decision Log Rules

Decisions are durable project memory. If it matters later, write it down.

## Required Format

Use this format in `00-control/decision-log.md`:

```markdown
## YYYY-MM-DD - Short Decision Name

- Classification: Decision
- Decision:
- Context:
- Options Considered:
- Evidence Used:
- Tradeoffs:
- Consequences:
- Revisit Trigger:
```

## What Counts As A Decision

- Target user selection
- Problem framing
- Research depth
- Positioning
- MVP or experiment choice
- Constraints
- Strategy
- Roadmap priority
- Pivot, pause, or stop choice

## Rules

- Preserve rejected options.
- Do not rewrite history. Add dated updates instead.
- If a decision changes, add a new decision entry and link the old one.
