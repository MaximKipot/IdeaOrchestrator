## Questions

- What path is selected now?
- What is deferred, rejected, or paused?
- What milestones are needed?
- What decision should be revisited after evidence arrives?
- Which decisions remain Active, and which are Superseded, Rejected, Deferred, or Archived?
- Why might the selected path be wrong?
- Does execution need an implementation spec before work starts?
- Will AI agents need execution rules before work starts?
- Does the handoff need Spec Kit compatible prompt output, verification expectations, non-goals, or forbidden assumptions?

## Blocking Conditions

- Selection criteria are unclear.
- Rejected alternatives are not preserved.

## Done When

- Selected path and roadmap are recorded.
- Challenge findings and stop/pivot triggers are recorded.
- Decision log is current.
- Phase 10 prep needs are explicit: implementation spec, agent execution rules, both, or neither.
- The next recommended skill is `idea-o-10-implementation-spec`, `idea-o-10-execution-rules`, or `idea-o-10-execution`.
