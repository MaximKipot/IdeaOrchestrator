# Phase 00: Project Setup

## Purpose

Create the working project folder, establish current state, choose depth, and confirm the first phase.

## Read

- `README.md`
- `AGENTS.md`
- `00-control/current-state.md` if it exists

## Write

- `00-control/current-state.md`
- `00-control/open-questions.md`
- `00-control/decision-log.md`

## Questions

- What is the project name?
- What is the raw idea in one or two sentences?
- What depth should be used: `Light`, `Standard`, or `Deep`?
- Are there known constraints, deadlines, or forbidden directions?

## Blocking Conditions

- No project folder exists.
- The raw idea is too vague to capture.

## Done When

- Project files exist.
- Current phase, depth, owner, and next action are recorded.
- The next recommended phase is `idea-intake`.
