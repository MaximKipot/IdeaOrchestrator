# Smallest Useful Experiment

## Selected Experiment

- Classification: Decision
- Offer a $99 manual guest communication audit and rewrite to 3 small inn owners.

## Why This Is Smallest Useful

- It tests demand, willingness to share materials, and perceived value without building software.

## What It Tests

- Willingness to engage.
- Willingness to pay.
- Usefulness of the deliverable.

## What It Does Not Test

- Scalable software workflow.
- Long-term retention.
